# MapLanguageAddon

MapLanguageAddon is a Minecraft plugin designed to translate text within maps, providing a seamless multilingual experience for players. This addon allows users to translate map text into various languages, enhancing communication and accessibility in multiplayer environments.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in your server's `plugins` directory.
3. Restart or reload your server to load the plugin.

## Use

1. Create a map with text in your desired language.
2. Use the `/ciao` command to greet players and demonstrate the plugin's functionality.
